# Immunis, Inc.

> Immunis, Inc. is a private, clinical-stage biotechnology company in Irvine, California developing
> immunomodulatory secretome biologics — the mixture of proteins and factors secreted by stem cells,
> rather than the cells themselves — for age- and disease-related immune decline.

Immunis publishes NO developer program and NO API. There is no developer portal, no documentation
site, no OpenAPI/AsyncAPI/GraphQL/gRPC/SOAP contract, no SDK or package on any public registry, no
MCP server, no A2A agent card, no webhooks and no /llms.txt of the company's own. This file is
generated by API Evangelist from the company's public web surface; it is not published by Immunis.

The only machine-readable endpoint on immunisbiomedical.com is the default WordPress REST API at
https://immunisbiomedical.com/wp-json/ (WordPress core plus Jetpack, Yoast, Akismet, Contact Form 7
and HubSpot plugin namespaces). That is the content-management interface of the marketing site, not
an Immunis product API, and it is not catalogued as one.
